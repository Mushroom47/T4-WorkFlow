## 可复现命令

以下命令在项目根执行，主工具和数据审计只需Python标准库：

```bash
python3 tools/reference_suite.py audit --output datasets/agenthon-t4-reference/qa/audit.json
python3 tools/audit_reference_data.py --self-check
python3 -m unittest discover -s tests -v
python3 tools/reference_suite.py validate \
  --answers-dir datasets/agenthon-t4-reference/qa/local-fixtures \
  --output datasets/agenthon-t4-reference/qa/validate.json
python3 tools/reference_suite.py compare \
  --answers-dir datasets/agenthon-t4-reference/qa/local-fixtures \
  --output datasets/agenthon-t4-reference/qa/compare-verified.json
python3 tools/reference_suite.py compare \
  --answers-dir datasets/agenthon-t4-reference/qa/local-fixtures \
  --allow-provisional \
  --output datasets/agenthon-t4-reference/qa/compare-all.json
```

按单题生成本地结构测试答案：

```bash
python3 tools/reference_suite.py fixture \
  --task-id t4-credit-event-2023 \
  --allow-provisional \
  --output /tmp/t4-experiment/t4-credit-event-2023/answer.json
python3 tools/reference_suite.py compare \
  --answer /tmp/t4-experiment/t4-credit-event-2023/answer.json
```

默认批量目录需覆盖完整11题；部分实验使用显式 `--allow-partial`，报告仍保留 `complete=false` 和缺题列表。单文件 `--answer` 用于单题实验。数据根可通过子命令前的 `--data-root` 指定。

官方确定性检查需要Python>=3.13和固定依赖；本次在被Git忽略的`.local/validation-venv`安装，精确锁定见根目录 `requirements-validation.lock.txt`，没有下载NLI模型或调用House：

.local/validation-venv/bin/python -m pip install -r requirements-validation.lock.txt

  --official-root /tmp/agenthon-t4-research-20261007 \
  --answers-dir datasets/agenthon-t4-reference/qa/local-fixtures \
