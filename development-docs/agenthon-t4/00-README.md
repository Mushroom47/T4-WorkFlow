# Agenthon 2026 T4 参赛准备

核对日期：2026-10-07（Asia/Hong_Kong）。目标是完成第四赛道 Explainability 的参赛准备：表格实体预测、冻结语料证据、区间与可选理由。当前已获授权持续执行公开历史参考集、本地验证工具、一次有效官方评测及最终交付。参赛候选和官方得分尚未完成。

## 先读结论

- T4 支持 `classification`、`regression`、`ranking`；公开 11 个 unit 只是格式练习，不能当隐藏题范围。
- 正式生成模型使用主办方 House route。自带语言模型/adapter 已取消；神经 embedding/reranker 等辅助模型另需明确批准。非神经数值预测与校准产物在满足 cutoff/披露要求时可用。
- 每 unit 全流程共享 25 次 admitted generation request、每次最多 4,000 输出 token。旧累计 token 额度已撤销。
- 当前评分器 5.2.2 对错误事实 claim 逐条扣分；旧 80% faithfulness 准入门槛已不适用。Development 不执行 NLI 矛盾检查；其通过不证明 Final 全检查通过。
- 可选顶层 `submitted_reasons` 与 `claims` 是两条不同评估路径；Final 理由加分不显示在 Development 榜。
- 最后 Development 运行启动期限是香港时间 **10 月 13 日 04:00**，早于报名/上传截止 **10 月 13 日 19:59**。Final 截止 **10 月 26 日 19:59**，每队每赛道一次且不能重交。
